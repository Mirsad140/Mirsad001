# مِرصاد — نسخة 01

مشروع أندرويد يحتوي ملف HTML المعتمد لنسخة 01.

## التوافق
- الحد الأدنى: Android 6.0 (API 23).
- يعمل على الهواتف والتابلت.
- يدعم الشاشات الصغيرة والعادية والكبيرة وX-Large وكثافات العرض المختلفة.
- يدعم الوضع الطولي والعرضي وتغيير حجم النافذة.
- يدعم اتجاه العربية RTL.
- الروابط الخارجية تفتح في المتصفح أو التطبيق المناسب.
- بيانات الحفظ والإعدادات تستخدم التخزين المحلي داخل WebView.

## ملاحظات مهمة
لا يمكن ضمان التوافق الحرفي مع كل جهاز وكل نسخة أندرويد، لأن جودة WebView تختلف بحسب تحديث Android System WebView. لكن إعدادات المشروع تغطي نطاقًا واسعًا من Android 6.0 فما بعد.

## البناء
يمكن فتح المشروع في Android Studio، أو رفعه إلى GitHub وتشغيل GitHub Actions. الناتج التجريبي يكون:
`Mirsad-01-Universal.apk`
